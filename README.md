# Hotel_Reservation
A console-based hotel reservation application developed as part of the Udacity Java Developer program. The project simulates a real-world hotel booking system where users can search for available rooms, make reservations, and view their bookings.

The application is built using core Java concepts such as object-oriented programming, collections, and layered architecture. It includes separate service layers to manage customers, rooms, and reservations, ensuring modular and maintainable code.

The system allows customers to create accounts, check room availability for specific dates, reserve rooms, and receive booking confirmations. This project demonstrates practical implementation of Java programming principles, data structures, and application design.
